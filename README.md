# OtterNote

Trabalho de Desenvolvimento de Interfaces Web - PUC Minas.

Sistema web para organização acadêmica: tarefas, provas, trabalhos e eventos escolares.

- **Entidade principal:** Atividades (título, autor, categoria, ano, status, prioridade, formato)


## Histórico de versionamento: 
#### Etapa 1 — HTML e estrutura da interface
Estrutura semântica com cadastro, listagem (dados fictícios), pesquisa, filtros, ordenação, detalhes e botões de editar/excluir (ainda sem funcionamento).

#### Etapa 2 — CSS, layout e responsividade
Identidade visual própria (cores, tipografia e espaçamentos em variáveis CSS), layout construído com Grid (cabeçalho/conteúdo/aside/rodapé) e Flexbox (navegação, formulários, ações), componentes de interface (botões, badges de status/prioridade, alertas, cartões), estados de interação (`:hover`, `:focus-visible`, `:disabled`) e responsividade com breakpoints em 900px e 600px, sem rolagem horizontal. Funcionalidades em JavaScript continuam pendentes para a próxima etapa.
